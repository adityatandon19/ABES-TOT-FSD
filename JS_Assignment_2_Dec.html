JavaScript Practice Assignments

A roadmap of 10 essential tasks to master DOM manipulation & logic.

Assignment 01

Read Input & Display

Create a page where a user types their name and gets a greeting.

Requirements

  • getElementById()
  • .innerHTML
  • No alert()
Assignment 02

Simple Calculator

Take two numbers and perform basic arithmetic operations via buttons.

Requirements

  • One function per button
  • Display result in <p>
  • Number() conversion
Assignment 03

Change Page Style

Modify DOM CSS properties dynamically on button clicks.

Core Concepts

  • element.style.color
  • .style.fontSize
  • doc.body.style.bg
Assignment 04

String Utilities

Manipulate user input strings: count, uppercase, and reverse.

Methods

  • .length property
  • .toUpperCase()
  • .split('').reverse().join('')
Assignment 05

To-Do List

A functional list where users can append new items dynamically.

Key Logic

  • 1. Capture Input value
  • 2. Select <ul> parent
  • 3. Use innerHTML +=
  • 4. Append <li>...</li> string
Assignment 06

Number Guessing

Generate a random number (1-10) and check user's guess.

Math Logic

Math.floor(Math.random() * 10) + 1

Compare with if/else.

Assignment 07

Light/Dark Mode

Toggle themes by changing background and text colors.

Requirements

  • Button 1: Light Mode
  • Button 2: Dark Mode
  • Optional: CSS Transition
Assignment 08

Live Char Counter

Real-time feedback showing total characters as the user types.

Event Listener

onkeyup="count()"

Read value.length and update UI.

Assignment 09

Image Switcher

Swap the source of an image tag on button click.

DOM Property

document.getElementById("img").src = "..."
Assignment 10

Form Validation

Validate inputs (Name, Email, Password) before "submitting".

Logic Checks

  • Fields not empty
  • Password >= 6 chars

UX / Feedback

  • Show errors in RED
  • Success: "Form Submitted"

Master these 10 tasks to build a solid JavaScript foundation.
