# Exercise: Create a 'Travel Blog' Webpage

## Objective:
To design a single-page travel blog layout using HTML only, practicing images, multimedia, links, lists, and anchors.

## Requirements:
1. Page title should be "My Travel Blog" - replace "My" with your name.
2. At the top, add a heading: "Welcome to My Travel Blog"
3. Include 3 destinations (e.g., Paris, Tokyo, Budapest). Each should have:
     - A subheading with the city name.
     - One image with alt text.
     - A short description in a paragraph.
     - A list of 2-3 activities.
4. Add an *internal navigation menu* at the top (links to jump to each destination using anchors)
5. Add an external link to a travel website (e.g., MakeMyTrip, TripAdvisor) that opens in a new tab.
6. Include an audio or video element (students can use any free MP3/MP4).
7. At the bottom, add a 'Back to Top' link.
